Docusaurus includes internationalization (i18n) features for building and maintaining a site in multiple languages. You can configure a default locale and additional locales, then use locale-specific commands to run or build the site.

## Localized content

For each locale, Docusaurus can load translated site UI strings and translated content. Docs, blog posts, and pages can have locale-specific versions. Docusaurus does not automatically translate source-language content; translations must be provided separately.

The `write-translations` command creates files for translating theme and interface text. Documentation and other content can be translated into the matching locale directory under `i18n/`. This keeps each translation alongside the corresponding site content without changing the source-language files.

## Locale selection and URLs

Docusaurus can expose locales under distinct URL paths, and you can add a locale dropdown to the navbar to let readers switch languages. The default locale can optionally be served from the site root, with other locales under paths such as `/fr/`.

## This site's current setup

This site currently configures English as its only locale in `docusaurus.config.js`. Adding a locale there enables Docusaurus to build and serve that locale, but it does not automatically translate existing articles; their translated versions and any UI translations still need to be supplied.
